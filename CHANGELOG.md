# Changelog

## 0.1.4

- Build the basic Windows MSI with the MS-RL licensed WiX 5.0.2 tool, without automatically accepting newer maintenance-fee agreements.

## 0.1.3

- Validate the first executable selected from PowerShell's application search results when preparing the native Windows toolchain.

## 0.1.2

- Use a warm charcoal, warm white and terracotta palette throughout the native UI and application icon.
- Expose registered plugin capabilities before loading a dynamic library, with explicit cache and loaded sources.
- Update zgpui to 0.1.8 for fixed-strike emoji rendering and zmcpio to 0.5.2.
- Select the absolute native MSVC linker for Windows host tools and application builds.
- Extend the real CLI/MCP/plugin acceptance suite to 23 cases.

## 0.1.0

- Add the bounded `no_std + alloc` unified messaging core and an explicit capability catalogue.
- Add the versioned zplugin IM ABI, native plugin registration and built-in provider bundle.
- Add the zgpui desktop, JSON CLI, line-oriented RPC and zmcpio MCP server.
- Add real protocol transports with explicit backend, encryption and platform boundaries.
- Add per-account AI scopes, host-assigned caller identity and bounded mutation deduplication.
- Add dependency-ordered crates.io publication, zdistro packaging and manual version bump releases.
